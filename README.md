# Тестовое задание для YADRO Импульс

Этот репозиторий содержит решение тестового задания команды разработки подсистемы GSM-базовой станции.

## Сборка

Для сборки используется GNU Make. Есть три основных таргета:
- `all` (по умолчанию) - собрать программу с оптимизациями
- `debug` - собрать программу без оптимизаций и с санитайзерами
- `clean` очистить файлы сборки

Между вызовами `make all` и `make debug` необходимо делать `make clean`.

Исполняемый файл разположен по пути `./build/csvreader`

Пример:
```sh
make
./build/csvreader test/basic.csv

```
